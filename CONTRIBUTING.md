# Contributing

## Branches
`main` ← `develop` ← `feature/<module>`. Không push trực tiếp main.

Các nhánh phân công ban đầu:

- `feature/tran-trong-duy-emr-report-notification`
- `feature/nguyen-nhat-dang-khoa-reception-consent-billing`
- `feature/luu-co-thanh-treatment-inventory-rules`
- `feature/tran-ngoc-chi-thanh-auth-clinical-services-audit`

## Commit
`feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`. Ví dụ: `feat(emr): add medical record form`.

## Pull request
Build/test thành công, chỉ thay đổi đúng module, mô tả API/schema impact và có reviewer module liên quan.
