# Project Tree

- `src/app`: routes/pages
- `src/features`: frontend module boundaries
- `src/server`: controllers/services/repositories/validators/mappers/policies/jobs
- `src/domain`: entities/enums/errors
- `src/infrastructure`: Prisma implementations
- `prisma`: database skeleton
- `tests`: unit/integration/e2e
- `docs`: module, API and diagrams
